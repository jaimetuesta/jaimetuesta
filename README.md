## Jaime Tuesta de Simón

Third-year student of **Mathematical Engineering and Artificial Intelligence** at ICAI – Universidad Pontificia Comillas (Madrid), graduating in 2028. Interested in data science, machine learning and software development.

### Selected projects

| Project | What it is |
|---|---|
| [Student dropout prediction](https://github.com/jaimetuesta/student-dropout-prediction) | Classification, regression and clustering on 4,424 university students (scikit-learn). Macro F1 = 0.72 for the final outcome, R² = 0.78 for second-semester grades. |
| [Madrid GPS](https://github.com/jaimetuesta/madrid-gps-routing) | Command-line route planner on the OpenStreetMap street graph of Madrid: own Dijkstra implementation, three cost functions, fuzzy address search and turn-by-turn directions. |
| [Amazon reviews with MySQL, MongoDB and Neo4j](https://github.com/jaimetuesta/amazon-reviews-mysql-mongodb-neo4j) | Data platform for about 770,000 reviews: relational and document storage, visualisation, graph analysis and popularity-based recommendations. |
| [Intelligent agents](https://github.com/jaimetuesta/intelligent-agents-logic-bayes-mdp) | Logical agent, Bayesian belief updates and an MDP solved with value iteration, in an *Apocalypse Now*-inspired scenario. |
| [Monte Carlo methods](https://github.com/jaimetuesta/monte-carlo-methods) | Monte Carlo integration: convergence rate, hit-or-miss, importance sampling, comparison with the rectangle rule and integration up to 10 dimensions. |
| [Modular arithmetic and RSA](https://github.com/jaimetuesta/modular-arithmetic-rsa) | Number theory library (Cipolla, Lehmer, general congruence systems) and an educational RSA implementation with two attacks. |

All projects started as university coursework. Group projects credit every author in their README.
